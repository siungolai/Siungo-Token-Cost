## 1. 项目概览

**定位**：公开、可自部署的 AI Token 价格计算工具站——按 **¥/1M tokens** 三档价格（命中输入 / 未命中输入 / 输出）估算多模型成本；计算公开免登录，模型/价格管理需管理密码（`ADMIN_PASSWORD`，缺失拒绝启动）。

### 1.1 技术栈

| 层 | 选型 |
|---|---|
| 后端 | Go 1.26（标准库 `net/http`）+ SQLite（`modernc.org/sqlite` 纯 Go 驱动，无 CGO） |
| 前端 | React 19 + TypeScript + Tailwind CSS 4 + Vite |
| 部署 | Linux 单二进制（前端 go:embed 内嵌）+ systemd + nginx 子路径 `/token-cost/` 反向代理 |

### 1.2 功能清单

- **三档价格**：命中输入 / 未命中输入 / 输出，单位 ¥/1M tokens（0 回退基础价）
- **缓存命中率**：每个模型可配置默认命中率（0-100），计算时可覆盖
- **谷峰定价**：默认峰值时段 22:00-8:00，支持自定义（可跨天）；优先级：自定义价 > 峰值价 > 基础价
- **多模型对比**：多选模型（第一个为主模型），按成本升序排名，绿省红贵
- **计算明细**：总成本卡 + 峰值状态横幅 + 每模型分项卡片（命中/未命中/输出、缓存节省、峰值溢价）+ 对比表 + 一键复制结果
- **文件上传估算**：上传文本文件（≤10MB）粗略估算 token（约 3 字符/token）
- **本地场景预设**：保存/应用/删除/收藏常用参数组合，存访客浏览器 localStorage，**不上传服务器**
- **管理模式**：右上角低调 ⚙ 入口；模型增删改（含**删除**，需确认、价格级联删除）、峰值/自定义价格配置
- **暗色模式**：跟随系统偏好，可手动切换

## 2. 构建

```bash
bash scripts/build.sh        # Windows 用 "C:\Program Files\Git\bin\bash.exe" scripts/build.sh
# 产物：server/bin/token-cost-server —— linux/amd64 单二进制（内嵌前端）
```

脚本流程：`vite build` → 同步 `web/dist` 到 `server/static` → 交叉编译 Go 二进制（无 CGO）。

> ⚠️ 改前端后必须完整重新构建才生效——`go:embed` 在编译时快照 `server/static`。

## 3. 部署（生产）

```
公网用户 → nginx:443 (https://你的域名/token-cost/)
             └→ 反向代理（剥离 /token-cost 前缀）
                  └→ siungo-token-cost.service（systemd，监听 127.0.0.1:8089）
                        └→ SQLite: /opt/siungo-token-cost/data/token-cost.db
```

### 3.1 前置条件

- 服务器需 **systemd + nginx**，SSH 别名已配置。`scripts/deploy.sh` 使用别名 `siungo`（如需修改，改脚本顶部 `REMOTE` 变量）：

  ```text
  # ~/.ssh/config
  Host siungo
      HostName 你的服务器地址
      User 你的登录用户
  ```

- 有域名的 TLS 证书（nginx 443 站点）。

### 3.2 服务器首次初始化

```bash
REMOTE_DIR=/opt/siungo-token-cost
ssh siungo "sudo mkdir -p $REMOTE_DIR/{bin,data} && sudo chown -R www-data:www-data $REMOTE_DIR"
ssh siungo "echo 'ADMIN_PASSWORD=替换为强密码' | sudo tee $REMOTE_DIR/.env && sudo chown www-data:www-data $REMOTE_DIR/.env && sudo chmod 600 $REMOTE_DIR/.env"
```

### 3.3 部署（含后续更新）

```bash
bash scripts/deploy.sh
# 本地构建 → rsync 二进制与 systemd 单元 → （重）启服务 → 健康检查
```

### 3.4 nginx 接入

把 `scripts/nginx-token-cost.conf` 的 `location /token-cost/ { ... }` 块复制进主站 443 server 块，然后 `nginx -s reload`。`proxy_pass http://127.0.0.1:8089/;` 末尾的 `/` 剥离前缀，后端无需感知前缀。

公网建议在 nginx 层对 `/token-cost/api/` 启用限流（`limit_req`，如每 IP 60 req/min，默认关闭，见脚本内注释）。

## 4. 配置

| 环境变量 | 必填 | 默认 | 说明 |
|---|---|---|---|
| `ADMIN_PASSWORD` | **是** | — | 管理密码；缺失拒绝启动。bcrypt 校验，登录后签发 24h HMAC token |

其余为命令行参数：`-addr`（默认 `127.0.0.1:8089`）、`-data`（默认 `data/token-cost.db`）。

## 5. API 文档

基础路径 `/api`（经 nginx 为 `/token-cost/api`）。

### 5.1 公开接口（无需认证）

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/health` | 健康检查 |
| GET | `/models` | 模型列表（含全部价格配置） |
| GET | `/models/{id}` | 单模型详情 |
| POST | `/calculate-price` | 价格计算（支持 `compare_model_ids` 多模型对比） |

请求示例：

```json
{
  "model_id": 1,
  "input_tokens": 1000000,
  "output_tokens": 200000,
  "cache_hit_rate": null,
  "compare_model_ids": [2, 3],
  "use_custom_hours": false
}
```

### 5.2 管理接口（需 `Authorization: Bearer <管理token>`）

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/admin/login` | 登录，body `{"password":"..."}` → `{token, expires_at}` |
| POST | `/models` | 新建模型 |
| PUT / DELETE | `/models/{id}` | 更新 / 删除模型（价格级联删除） |
| GET / POST | `/models/{id}/prices` | 查看 / 新建价格配置 |
| PUT / DELETE | `/models/{id}/prices/{priceId}` | 更新 / 删除价格配置 |

## 7. 安全设计

| 风险 | 对策 |
|---|---|
| 公网写接口被恶意修改 | 全部写操作需管理 token；密码来自环境变量，不入代码不入库 |
| 管理密码被爆破 | 登录失败 5 次锁 10 分钟（按客户端真实 IP 内存计数，重启清零；反代下取 X-Forwarded-For 首个 IP，直连忽略该头防伪造） |
| 计算接口被刷 | nginx 层对 `/token-cost/api/` 限流（如每 IP 60 req/min，可选，默认关闭） |
| token 泄露 | 有效期 24h；无状态 HMAC 签名，密钥随进程生成，服务重启即全部失效；缺失/非法/过期统一 401 不区分提示 |
| 跨站写请求 | 管理接口为非简单请求（JSON + Authorization），跨站浏览器请求被 CORS 预检拦截；静态与公开 API 的 `ACAO: *` 不影响此保护 |
| 输入校验 | 模型名 ≤100 字、服务商 ≤50 字、价格非负、命中率 0-100、价格配置至少一项 >0、时间 HH:mm |

其他约定：
- 服务只监听 `127.0.0.1`，不直接暴露公网
- SQL 全参数化，无注入面
- 登录接口不记录密码；日志只输出启动信息

## 9. 已知限制（v1）

- 种子价格为 **2026-08-27 快照**，无自动同步；官方调价需在管理模式手动更新
- 海外模型人民币价按快照日汇率（约 1 USD ≈ 6.72 CNY）折算，不随汇率浮动
- 文件上传 token 估算为粗略值（约 3 字符/token），非官方 tokenizer
- 单一共享价格库，无多用户/权限体系（公开工具定位）
- 场景预设只存访客浏览器 localStorage，服务器不保存
- 登录限速按 IP 内存计数：单实例有效，重启清零

## 11. 故障排查

| 现象 | 原因 / 处理 |
|---|---|
| 白屏或页面无样式 | 静态托管必须同时具备 `/token-cost/` 前缀剥离 与 `Access-Control-Allow-Origin: *`（Vite 产物带 crossorigin）。两者在 `server/main.go` 的 `handleStatic`，改动务必保留 |
| 服务启动即退出 | `ADMIN_PASSWORD` 未设置。检查服务器 `.env` 存在、属主 www-data、权限 600、systemd `EnvironmentFile=` 路径一致 |
| 管理写操作 401 | token 过期（24h）或服务重启过 → 重新登录 |
| 改前端不生效 | `go:embed` 是编译时快照 → 重跑 `scripts/build.sh`（或本地：`npm run build` → 同步 `server/static` → `go build`） |
| 子路径下 API 404 | nginx `proxy_pass` 必须以 `/` 结尾（剥离前缀） |
| 登录全被锁 | 反代场景下所有访客共享 127.0.0.1 时代？—— 不会：限速 key 已按 X-Forwarded-For 取真实 IP（2026-08-27 修复） |

## 12. 本地环境坑（Windows 实测）

- npm 缓存必须指工作区：`npm install --cache <ws>\.npm-cache`（写用户 AppData 会被环境限制拒绝）
- Go 构建：`GOCACHE/GOMODCACHE` 指工作区 + `GOPROXY=https://goproxy.cn,direct`（build.sh 已内置）
- **PowerShell 传 exe 参数 `-addr=127.0.0.1:8089` 等号连写会被拆坏（只剩 `127`）→ 必须空格分隔：`-addr "127.0.0.1:8089"`**
- PowerShell 调 curl.exe 传 JSON：双引号会被剥 → body 写临时文件 `-d @file`，文件必须 UTF-8 无 BOM（`[System.IO.File]::WriteAllText`）
- 跑 `.sh` 用 `C:\Program Files\Git\bin\bash.exe`（PATH 里的 bash 指向未安装的 WSL）
- 杀进程：`Get-Process -Name token-cost-server | Stop-Process -Force`（或按端口定位）
- vite build 在受限沙箱下会 spawn EPERM / 原生模块加载失败 → 需在非受限环境执行

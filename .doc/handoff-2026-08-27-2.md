  - npm cache 必须指工作区（`--cache <ws>\.npm-cache`）
  - Go 构建需 `GOCACHE/GOMODCACHE` 指工作区 + `GOPROXY=https://goproxy.cn,direct`
  - PowerShell 调 `curl.exe` 时 JSON 双引号会被剥掉 → body 写临时文件用 `-d @file`；**且 `Set-Content -Encoding UTF8` 会写 BOM 导致 JSON 解析失败，必须用 `[System.IO.File]::WriteAllText` 或 UTF8 无 BOM 方式**
  - 跑 `.sh` 脚本必须用 `C:\Program Files\Git\bin\bash.exe`（PATH 里的 bash 指向未安装的 WSL）
  - 杀 Go 进程用 `Get-Process -Name token-cost-server | Stop-Process -Force`（job 管理或按端口）
- 改前端后必须：`npm run build` → 产物同步 `server/static/` → 重新 `go build`（go:embed 编译时快照，不重新编译不生效）
- 子路径部署铁律：Go 静态托管已内置 `/token-cost/` 前缀兼容 + `Access-Control-Allow-Origin: *`，两者缺一不可（Vite crossorigin 特性）

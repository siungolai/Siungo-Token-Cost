### 具体改动清单

**① 模型选择器紧凑化 — `web/src/components/tokencalc/ModelSelector.tsx`**
- 改了什么：`ModelRow` 由"左侧名称/服务商 + 右侧价格三行竖排"改为单行紧凑布局——价格横排 `命中 ¥x · 未命中 ¥x · 输出 ¥x`（命中绿色 `text-emerald-500 dark:text-emerald-400`，未命中/输出灰色；`base_input_hit_price <= 0` 时自动省略命中段）；外层容器 `items-start` → `items-center`，`py-2.5` → `py-2`；列表滚动区 `max-h-72`（288px）→ `max-h-[400px]`。
- 为什么：原行高约 85px、列表 288px，同框仅 3 个模型；紧凑后同框 8~10 个。
- 注意：名称区 `flex-1 min-w-0` + `truncate` 防挤压价格区；徽章（命中率/峰值价）`shrink-0`。

**② 分项成本表格（新组件）— `web/src/components/tokencalc/BreakdownTable.tsx`（新增）**
- 结构：行=模型，列=输入成本（缓存命中）/输入成本（缓存未命中）/输出成本/缓存节省/有效成本；主模型固定首行 + 高亮底 `bg-surface-alt dark:bg-[#1a1a1a]` + 「（当前）」标记；缓存节省列 emerald 色 + `title` tooltip（命中率/命中与未命中 tokens/节省占比）；进度条仅主模型行保留（`h-1 w-full` emerald，宽度 = `savings_percentage` 夹取 0-100）。
- 布局决策：`table-fixed` + `<colgroup>` 模型列 `w-[26%]`，5 数值列均分余量；表头两行短词（`输入成本/缓存命中`），完整列名放 `title`；数值单元格 `overflow-hidden whitespace-nowrap text-right tabular-nums`；外层 `overflow-x-auto` 供移动端降级滚动。
- 为什么：用户要求"一个表格组件、行=模型、列=五个成本项"；先尝试压缩字号（11px）被用户否决（"字体不要改小"），最终改为加宽右栏容纳原字号（12px 表头 / 14px 数值）。
- 数据流：`PriceResult` 组装 `rows`（主模型 breakdown/cache_info + `model_comparison` 各项）传入，保持单一数据源。

**③ 结果区表格化 — `web/src/components/tokencalc/PriceResult.tsx`**
- 删除了 `Row` 组件与 `renderBreakdown` 函数（原每模型一张竖排卡片）；分项明细区替换为 `<BreakdownTable rows={[...]} />`。
- 峰值状态条增强：`峰值溢价 +${fmtMoney(b.peak_surcharge)}（${fmtPct(pi.peak_surcharge_rate * 100)}）`——显示具体溢价金额（原来只有百分比），与表格"有效成本"口径呼应（effective_cost 已含溢价）。
- 决策：不设"峰值溢价"列（用户敲定 5 列制），溢价由状态条承担。

**④ 页面布局与权限 — `web/src/pages/ToolsTokenCalculator.tsx`**
- 容器 `max-w-5xl` → `max-w-6xl`；网格 `lg:grid-cols-2` → `lg:grid-cols-[5fr_7fr]`（左输入区 5 / 右结果区 7）。

## 4. 设计规范参考

**设计 token（与主站摄影站同步，`web/src/index.css` 的 Tailwind v4 @theme 语义变量 + `.dark` 覆盖）：**

| Token | 亮色 | 暗色 | 用途 |
|-------|------|------|------|
| `--color-surface` | #ffffff | #1a1a1a | 页面/卡片背景 |
| `--color-surface-alt` | #f5f5f5 | #2a2a2a | 次级背景（选中行、hover） |
| `--color-text-primary` | #1a1a1a | #e5e5e5 | 主文本 |
| `--color-text-secondary` | #737373 | #a3a3a3 | 次级文本 |
| `--color-border` | #e5e5e5 | #333333 | 边框/分隔线 |
| `--color-primary` | #1a1a1a | #e5e5e5 | 主按钮/强调 |
| `--color-primary-light` | #4a4a4a | #d4d4d4 | 主按钮 hover |

- 语义类用法：`bg-surface dark:bg-surface-alt`、`border-border`、`text-text-primary`、`btnPrimaryCls` 含 `dark:bg-[#e5e5e5] dark:text-[#1a1a1a]`（主按钮暗色反白，与主站一致）。
- 强调色：绿色 `text-emerald-600 dark:text-emerald-400`（缓存节省/便宜）、红色 `text-red-600 dark:text-red-400`（更贵）、琥珀 `bg-amber-50 dark:bg-amber-900/30`（峰值时段）。
- 字体：Inter（Google Fonts `@import`），`--font-sans`。
- 圆角：卡片 `rounded-lg`、按钮 `rounded-md`、徽章 `rounded`。
- 布局：容器 `max-w-6xl`、两列 `lg:grid-cols-[5fr_7fr]`、卡片内边距 `p-4`、网格 `gap-3`。
- 表格：表头 `text-xs` 两行短词、数值 `text-sm`（继承 table）、单元格 `px-2 py-2`、模型列 `w-[26%]`。

**主题机制**：localStorage key `theme`（与主站共用，同源自动同步；旧 key `studio_theme` 读即迁移）；`main.tsx` 渲染前 `applyTheme(readInitialTheme())` 防闪烁；切换按钮在右上角（Sun/Moon 内联 SVG）。
